## Context Engineering

上下文工程相关技术与方法


## 定义：

根据当前任务动态构建最有效的LLM输入上下文。


## 流程：

 Information
    ↓
  Filter
    ↓
  Compress
    ↓
  Select
    ↓
  Context
    ↓
   LLM


##  一个企业Agent的Context通常包括：
Context

├── System Prompt
│
├── Current Task
│
├── Short Memory
│
├── Long Memory
│
├── Knowledge(RAG)
│
├── Tool Result
│
└── Conversation History


## 1. 为什么需要Context Engineering？

答案：因为LLM上下文窗口有限，需要动态选择、压缩和组织信息，提高回答质量。

## 2. Memory和RAG区别？

答案：
	    Memory	     RAG
目标	记住用户	查询知识
内容	个人信息	外部知识
来源	交互历史	文档
存储	VectorDB/DB	VectorDB

## 3. 为什么Memory不能全部保存？

因为：
信息过多
噪声增加
检索困难

需要：Memory Retrieval + Context Selection
