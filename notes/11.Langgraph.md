## Agent = State + Node + Edge 的状态机。

## 1. State是什么？
答案：State是Agent运行过程中共享的数据结构，用于保存目标、计划、记忆、观察结果和最终结果。所有Node通过State通信。
State是Agent状态机中的状态数据，
LangGraph通过Node修改State，
通过Edge控制State流转，从而形成Agent状态机。

## 2. Node和普通函数区别？
普通函数：

输入参数
 ↓
返回结果

Node：

读取State
 ↓
修改State
 ↓
返回State

Node代表Agent中的一个行为。

## 3. Graph比while循环好在哪里？
while:
随着功能增加：
Memory
RAG
Human approval
Multi-Agent
会越来越复杂。

Graph:
显式表达：节点 + 边 + 条件流转

优点：
1. 可视化：知道Agent怎么走。
2. 可扩展：增加节点即可。
3. 支持暂停恢复：如人工审核
4. 状态持久化：可以保存Graph运行状态。
