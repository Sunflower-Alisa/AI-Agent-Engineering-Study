## Planning（任务规划）
LLM 可以回答问题，但 Agent 需要 Planning 才能把复杂目标拆解成可执行步骤，并根据执行情况调整任务状态。


### 什么是Planning？
Planning 是 Agent 将复杂目标拆解成多个可执行步骤，并决定执行顺序的能力。

### Agent State
保存Agent当前任务状态，结构如下：
{
    goal:"",
    steps:[],
    completed:[]
}

### 分类

#### Static Planning （静态规划）
Agent 根据目标，一次性生成完整计划。

流程：
Goal
↓
LLM
↓
Plan
↓
Execute

#### Dynamic Planning （动态规划）
Agent 在执行过程中，根据新信息不断调整计划。

流程：
Goal
↓
Plan
↓
Execute Step1
↓
Observe Result
↓
Update Plan
↓
Execute Step2

#### 两者区别
| |静态规划|动态规划|
|-|-|-|
|计划时间|开始一次生成|执行中生成|
|调整能力|弱|强|
|复杂任务|一般|适合|
|成本|低|高|
