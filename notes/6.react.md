1、接地换幻觉是笔好交易,但要为「工具失败」设计恢复路径：生产 agent 必须处理工具返回空/报错后的重试、改写查询、换路径,否则接地反而成了单点故障
2、思考的密度应随任务调节：推理密集型任务每步都想(dense),长动作序列任务只在关键节点想(sparse),且可以让模型自己决定何时想。盲目每步强制长思考既烧 token 又可能画蛇添足
3、防复读循环是工程必修课:ReAct 特有的失败模式是原地打转。实践中要做循环检测(相同动作重复 N 次即打断)、温度/解码调整或强制注入反思步——这个 2022 年的坑,今天的 agent 依然在踩。
4、轨迹微调教「技能」优于教「知识」:用成功轨迹微调小模型,学「如何查」比学「答案是什么」泛化好得多,8B 微调即可反超 540B prompting——这正是今天蒸馏 agent 能力到小模型的路线雏形。
